Em 3D, arraste para girar; em 2D, para mover. Role para aproximar. O cursor ilumina o que está perto dele: passe por um ponto para ver as conexões, clique para abrir a entidade e dê duplo clique para focar na vizinhança.

Comece pelo grafo

Cada ponto de luz é uma entidade (técnica, modelo, dataset, organização, produto, problema ou regulação) extraída dos itens que a triagem aprovou, e o tamanho segue o número de itens que a citam. As linhas ligam entidades citadas no mesmo item; as mais claras são relações explícitas, como "desenvolvido por" ou "aborda".
